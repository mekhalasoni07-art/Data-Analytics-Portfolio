# 👩‍💼 HR Analytics Dashboard (Power BI)

## Overview
This project demonstrates my ability to use **Power BI** for HR data analysis and visualization. The dashboard provides actionable insights into workforce trends, employee performance, and attrition, helping HR teams make data-driven decisions. It reflects my skills in data transformation, DAX calculations, and interactive dashboard design.

## Objectives
- Analyze HR data to identify key workforce metrics.
- Build an interactive dashboard for HR managers and recruiters.
- Apply **Power Query** for data cleaning and shaping.
- Use **DAX measures** to calculate KPIs such as attrition rate, average tenure, and department-wise performance.
- Present insights in a clear, recruiter-facing format with professional visuals.

## Key Features
- **Employee Overview:** Total employees, new hires, attrition count, and retention rate.
- **Attrition Analysis:** Breakdown by department, age group, and job role.
- **Diversity Metrics:** Gender distribution and workforce composition.
- **Performance Insights:** KPIs highlighting productivity and tenure.
- **Interactive Dashboard:** Slicers and filters for drill-down analysis.

## Folder Structure
- `Dataset/` → HR dataset used for analysis.
- `PBIX/` → Power BI project file.
- `Screenshots/` → Dashboard visuals for quick recruiter review.
- `HR ANALYTICS DASHBOARD PI PROJECT.pdf` → Exported dashboard report.
- `README.md` → Documentation of objectives, steps, and insights.

## How to Use
1. Open the `.pbix` file in Power BI Desktop to explore the interactive dashboard.
2. Use slicers and filters to analyze HR metrics by department, age, or role.
3. Review the PDF report for a static recruiter-facing summary.
4. Check the `Screenshots` folder for instant visibility of key visuals.

## Insights & Takeaways
- Identified departments with the highest attrition rates, enabling targeted retention strategies.
- Highlighted workforce diversity metrics to support HR policy decisions.
- Demonstrated ability to design dashboards that balance technical depth with clarity.
- Recruiter-ready presentation with both interactive and static formats.
