# 📊 Excel Analytics Project

## Overview
This project demonstrates my ability to use **Microsoft Excel** for data cleaning, analysis, and visualization. It reflects my skills in transforming raw datasets into meaningful insights, supported by clear dashboards and professional documentation. The goal is to showcase analytical thinking, structured workflows, and recruiter-ready presentation.

## Objectives
- Apply Excel functions and formulas to solve real-world analytical problems.
- Perform data cleaning and preprocessing for accuracy and consistency.
- Use pivot tables, charts, and conditional formatting to highlight trends.
- Build an interactive dashboard that communicates insights effectively.
- Document the process with clear explanations and screenshots for instant visibility.

## Key Features
- **Data Cleaning:** Removal of duplicates, handling missing values, and formatting for consistency.
- **Analysis Techniques:** Use of lookup functions (VLOOKUP, INDEX-MATCH), logical functions (IF, AND, OR), and statistical measures (AVERAGE, COUNT, SUM).
- **Visualization:** Charts and graphs (bar, line, pie) to illustrate patterns and comparisons.
- **Dashboard:** A recruiter-facing dashboard with slicers and filters for interactive exploration.
- **Insights:** Actionable conclusions drawn from the dataset, presented in a concise summary.

## Folder Structure
- `Dataset/` → Raw and cleaned data files.
- `Analysis/` → Working Excel sheets with formulas and pivot tables.
- `Dashboard/` → Final interactive dashboard file.
- `Screenshots/` → Embedded visuals for quick recruiter review.
- `README.md` → Documentation of objectives, steps, and insights.

## How to Use
1. Open the `Dashboard` file in Excel.
2. Explore the slicers and filters to interact with the data.
3. Review the `Screenshots` folder for a quick preview of the dashboard and key findings.
4. Read through the analysis steps in the `Analysis` folder for transparency of methods.
