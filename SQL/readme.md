# 🍕 Pizza Sales SQL Project

## Overview
This project demonstrates my ability to use **SQL** for business analytics in the food and beverage industry. By analyzing pizza sales data, I extracted meaningful insights into customer preferences, revenue trends, and product performance. The project reflects my skills in query writing, data cleaning, and translating raw transactional data into actionable business intelligence.

## Objectives
- Explore pizza sales data to identify revenue drivers and customer behavior.
- Apply SQL queries to calculate KPIs such as total sales, average order value, and top-selling products.
- Use joins, aggregations, and window functions to uncover deeper insights.
- Present results in a recruiter-facing format with clear documentation and screenshots.

## Key Features
- **Sales Analysis:** Total revenue, order counts, and average order value.
- **Product Insights:** Top 5 best-selling pizzas by revenue and quantity.
- **Category Trends:** Performance comparison across pizza categories (Classic, Supreme, Veggie, etc.).
- **Time-Based Analysis:** Daily, monthly, and yearly sales trends.
- **Customer Behavior:** Order distribution and preferences highlighted through queries.

## Folder Structure
- `Dataset/` → Pizza sales dataset.
- `Queries/` → SQL scripts with comments explaining logic.
- `Results/` → Screenshots of query outputs.
- `Pizza_Sales SQL project.pdf` → Exported report with queries and results.
- `README.md` → Documentation of objectives, steps, and insights.

## How to Use
1. Review the SQL scripts in the `Queries` folder to understand the logic.
2. Execute queries on the provided dataset to replicate results.
3. Check the `Results` folder and PDF report for recruiter-facing outputs.
4. Read the insights section for conclusions and business impact.

## Insights & Takeaways
- Identified the **top revenue-generating pizzas**, helping prioritize product promotion.
- Highlighted **seasonal and monthly sales trends**, useful for inventory planning.
- Showcased ability to write optimized queries using joins, GROUP BY, HAVING, and window functions.
- Recruiter-ready presentation with documented queries and clear business insights.
